# Báo cáo Insight Khách sạn Vũng Tàu

Gói này dùng để đưa báo cáo HTML lên GitHub Pages.

## Cách dùng nhanh
1. Giải nén file zip.
2. Upload `index.html` lên repository GitHub mới.
3. Vào Settings → Pages.
4. Chọn Deploy from a branch → branch `main` → folder `/(root)` → Save.
5. Mở link GitHub Pages sau khi deploy xong.
