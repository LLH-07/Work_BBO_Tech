1. Kỹ sư Thiết kế Luồng Agent (Agentic Workflow Architect)
Agentic Workflow Architect / Engineer

🟢 TẦNG 1 — Đang hình thành (2024–2026)
Người thiết kế toàn bộ "não bộ vận hành" của một hệ thống AI agent trong doanh nghiệp — quyết định agent nào làm gì, giao tiếp với nhau thế nào, khi nào cần con người can thiệp, và khi nào agent có quyền tự hành động mà không cần hỏi ý kiến ai. Đây là nghề trực tiếp sinh ra vì phần mềm đang chuyển từ "nhận lệnh rồi làm" sang "tự suy nghĩ rồi tự làm".

Phục vụ loại DN nào? | • Fintech / Ngân hàng số: cần workflow tự động duyệt hồ sơ vay, KYC, fraud alert
• Bệnh viện tư / chuỗi phòng khám: cần workflow điều phối lịch khám, triage bệnh nhân
• Logistics / E-commerce: cần workflow từ đặt hàng → kho → giao hàng → CSKH không ngừng
• Doanh nghiệp sản xuất FDI: cần workflow từ cảm biến IoT → cảnh báo → tạo lịch bảo trì
• Startup AI đang xây sản phẩm agent: cần người thiết kế hệ thống trước khi team dev code

Phục vụ nhiều nhất | Ngân hàng và fintech trả nhiều nhất — vì một lỗi workflow agent chuyển tiền sai = thiệt hại hàng tỷ đồng.

Phục vụ như thế nào? | • Vẽ sơ đồ luồng: agent A làm gì → khi nào gọi agent B → khi nào escalate lên người
• Viết system prompt và chỉ thị cho từng "agent con" trong hệ thống
• Thiết kế cơ chế retry/fallback: agent thất bại thì làm gì thay vì đứng yên
• Code orchestration bằng LangGraph, AutoGen, CrewAI
• Test edge cases: agent sẽ làm gì khi dữ liệu đầu vào bất thường hoặc tool bị lỗi
• Trình bày cho C-level: tại sao thiết kế này an toàn và tạo ra giá trị gì

Ví dụ thực tế | Ngân hàng ACB muốn tự động 70% quy trình xử lý hồ sơ tín dụng SME. Workflow Architect thiết kế: Agent 1 đọc hồ sơ PDF → Agent 2 tra cứu CIC → Agent 3 chấm điểm tín dụng → nếu điểm >700 thì auto approve, nếu 500–700 thì flag cho chuyên viên review, nếu <500 thì auto từ chối và gửi lý do. Kết quả: thời gian xử lý từ 3 ngày xuống còn 4 giờ.

Kỹ năng cốt lõi | LangGraph / AutoGen / CrewAI; Python; tư duy hệ thống phân tán; enterprise API integration; kỹ năng trình bày cho non-tech stakeholder | Lương tham chiếu | $130k–$280k/năm (Mỹ). Glassdoor avg senior: $188k.
40–120 triệu VND/tháng. Remote quốc tế: $60–110/giờ

2. Chuyên gia Vận hành Agent (AgentOps Specialist)
AgentOps Specialist / Manager

🟢 TẦNG 1 — Đang hình thành (2024–2026)
DevOps ra đời để phần mềm chạy ổn định. AgentOps ra đời để AI agent chạy ổn định trong môi trường thật. Không phải lập trình agent — mà là giám sát agent đang chạy: nó có đang làm đúng không, tốn bao nhiêu tiền, chậm ở bước nào, và khi nào cần can thiệp trước khi agent "lạc đường". LangChain 2025: 32% tổ chức xếp chất lượng agent là rào cản số 1.

Phục vụ loại DN nào? | • Startup AI đã có agent chạy production và cần ổn định hóa
• Ngân hàng / bảo hiểm có agent xử lý hồ sơ — không thể để agent tự ý sai
• SaaS B2B đã tích hợp LLM vào sản phẩm, cần kiểm soát chi phí API
• BPO / outsourcing dùng agent thay nhân viên thực hiện task lặp lại
• Bệnh viện dùng agent hành chính — không thể để agent gửi sai thông tin bệnh nhân

Phục vụ nhiều nhất | SaaS B2B và ngân hàng — vì chi phí LLM không kiểm soát có thể tăng gấp 5–10 lần ngân sách dự kiến.

Phục vụ như thế nào? | • Theo dõi dashboard real-time: latency, error rate, token cost, task completion %
• Phân tích trace log khi agent thất bại — xác định đúng bước nào sai, tại sao
• Thiết lập alert tự động: agent vượt ngưỡng chi phí hoặc response time
• Viết và chạy regression test mỗi khi thay đổi prompt hoặc upgrade model
• Xây dựng golden test cases: bộ câu hỏi chuẩn đánh giá agent định kỳ
• Báo cáo tuần: agent tự hoàn thành bao % task, tiết kiệm bao nhiêu công sức người

Ví dụ thực tế | Startup fintech Timo Bank deploy agent CSKH xử lý 2.000 câu hỏi/ngày. AgentOps Specialist phát hiện agent đang trả lời sai câu hỏi về phí chuyển tiền trong 12% trường hợp (do prompt cũ). Không có AgentOps, lỗi này có thể kéo dài nhiều tuần. Sau khi fix: accuracy lên 98.5%, chi phí API giảm 30%.

Kỹ năng cốt lõi | LangSmith / Langfuse / Helicone; Python; prompt versioning; A/B testing; SQL log query; incident response; LLM cost optimization | Lương tham chiếu | $120k–$220k/năm. Tăng 30–50% so với DevOps truyền thống.
35–80 triệu VND/tháng. Remote toàn cầu: $55–100/giờ

📈 Tín hiệu thị trường: Prompt engineer roles tăng 135.8% YoY (Second Talent/PromptLayer 2025). AgentOps là evolution tất yếu của MLOps.

3. Kỹ sư Ngữ cảnh & Dữ liệu Agent (Context/RAG Engineer)
Context Engineer / RAG Data Engineer for Agents

🟢 TẦNG 1 — Đang hình thành (2024–2026)
"Agent thông minh tới đâu chỉ phụ thuộc vào dữ liệu nó được cung cấp." Context Engineer là người xây pipeline từ dữ liệu thô của doanh nghiệp đến context window của LLM — đảm bảo agent luôn có đúng thông tin, đúng lúc, đúng định dạng. Không có người này, agent giỏi nhất cũng trả lời sai vì không được cung cấp đủ ngữ cảnh. 80% RAG system thất bại ở data pipeline, không phải ở model.

Phục vụ loại DN nào? | • Công ty pháp lý / compliance: cần agent đọc và tra cứu hàng nghìn văn bản pháp luật
• Ngân hàng: cần agent biết toàn bộ sản phẩm, chính sách, lịch sử giao dịch khách hàng
• Bệnh viện / y tế: cần agent đọc hiểu hồ sơ bệnh án dạng PDF, Word, bảng điện tử
• Nhà máy sản xuất: cần agent biết manual máy móc, quy trình vận hành, lịch sử bảo trì
• Doanh nghiệp có nhiều tài liệu nội bộ (SOP, hợp đồng, báo cáo) muốn agent "biết tất cả"

Phục vụ nhiều nhất | Ngân hàng, pháp lý, y tế — vì sai sót do thiếu dữ liệu đúng đắn trong các ngành này có thể dẫn đến hậu quả pháp lý nghiêm trọng.

Phục vụ như thế nào? | • Thiết kế chunking strategy: cắt tài liệu như thế nào để retrieval chính xác nhất
• Xây embedding pipeline: từ PDF/Word/SQL/API → vector database có thể tìm kiếm
• Tối ưu hybrid search: kết hợp semantic search + keyword search để agent tìm đúng
• Làm sạch dữ liệu: xóa header/footer lặp, chuẩn hóa format, xử lý tiếng Việt có dấu
• Monitor retrieval quality: agent đang lấy đúng tài liệu không, hay đang "ảo tưởng"
• Thiết lập data freshness: khi chính sách thay đổi, re-index tự động trong bao lâu

Ví dụ thực tế | Công ty bảo hiểm Bảo Việt muốn agent tư vấn sản phẩm cho khách hàng qua Zalo. Context Engineer xây pipeline: 3.000 trang tài liệu sản phẩm + 500 trang điều khoản + câu hỏi FAQ → chunk → embed → Pinecone. Kết quả: agent truy xuất đúng điều khoản trong 1.2 giây, độ chính xác 94% vs. 61% khi không có RAG.

Kỹ năng cốt lõi | Vector DB (Pinecone/Weaviate/pgvector); Python; LangChain RAG; embedding models; data pipeline (Airflow); hiểu tokenization và chunking strategy | Lương tham chiếu | $120k–$200k/năm. +20–40% so với Data Engineer truyền thống.
35–90 triệu VND/tháng. Cực kỳ khan hiếm tại Việt Nam hiện nay

📈 Tín hiệu thị trường: "Context engineering" được đặt tên chính thức 2025, nhanh chóng trở thành skill được tìm nhiều nhất sau prompt engineering. ODSC: top 5 AI role 2026.

4. Chuyên gia Đánh giá Chất lượng Agent (AI Agent Evaluator)
AI Agent Evaluator / AI Quality Engineer

🟢 TẦNG 1 — Đang hình thành (2024–2026)
Nghề sinh ra từ một câu hỏi đơn giản nhưng chưa có ai trả lời được tốt: "Làm sao biết agent của mình đủ tốt để dùng thật?" AI Agent Evaluator xây dựng bộ tiêu chí và quy trình kiểm định có thể lặp lại — đo độ chính xác, phát hiện hallucination, kiểm tra hành xử khi gặp tình huống bất thường, và cung cấp bằng chứng cho ban lãnh đạo trước khi go-live.

Phục vụ loại DN nào? | • Ngân hàng / tín dụng: agent duyệt hồ sơ phải đúng 99%+ để không vi phạm luật tài chính
• Bệnh viện / y tế: agent triage không được phân loại sai mức độ khẩn cấp
• Pháp lý / compliance: agent tư vấn luật không được hallucinate tên điều khoản sai
• Startup AI muốn pitch enterprise client: cần eval report làm bằng chứng product-market fit
• Cơ quan nhà nước dùng AI: cần báo cáo kiểm định để trình hội đồng phê duyệt

Phục vụ nhiều nhất | Ngân hàng và bảo hiểm — regulated industries bắt buộc phải có documented evidence agent hoạt động đúng trước khi NHNN / NFSC cho phép triển khai.

Phục vụ như thế nào? | • Xây golden dataset: 200–1.000 câu hỏi + đáp án chuẩn theo từng use case cụ thể
• Chạy benchmark tự động dùng LLM-as-judge (AI đánh giá AI, có human review sample)
• Đo các metric cụ thể: accuracy, hallucination rate, refusal rate, consistency qua các lần
• Thiết kế red-teaming: cố tình thử các tình huống cực đoan để tìm điểm yếu
• Viết failure report: agent sai theo pattern nào, tần suất bao nhiêu, tác động như thế nào
• Lập eval dashboard: C-level nhìn vào thấy ngay "agent đang ở mức tin cậy bao nhiêu %"

Ví dụ thực tế | TPBank muốn deploy agent trả lời câu hỏi về tài khoản. AI Agent Evaluator chạy 800 test cases, phát hiện agent hallucinate tên sản phẩm trong 7% trường hợp và từ chối trả lời câu hỏi hợp lệ trong 12% trường hợp (over-refusal). Sau 3 vòng tune, accuracy đạt 97.8% và refusal rate giảm xuống 2.1% → đủ điều kiện go-live.

Kỹ năng cốt lõi | RAGAS / DeepEval / LangSmith (eval frameworks); thống kê cơ bản; Python; domain knowledge của ngành agent phục vụ; kỹ năng viết báo cáo kỹ thuật | Lương tham chiếu | $110k–$200k/năm. Nhu cầu cao nhất tại regulated industries.
30–70 triệu VND/tháng. Gần như chưa có người chuyên biệt tại Việt Nam

5. Chuyên gia Quản trị & Tuân thủ AI (AI Governance Specialist)
AI Governance Specialist / Director of AI Risk

🟢 TẦNG 1 — Đang hình thành (2024–2026)
Người đảm bảo doanh nghiệp dùng AI một cách hợp pháp, có trách nhiệm và không tạo ra rủi ro pháp lý hoặc thương hiệu. Không phải lập trình AI — mà là xây dựng chính sách, quy trình kiểm soát và chứng minh với cơ quan quản lý rằng AI của công ty đang vận hành đúng cách. 13. Tư vấn Pháp lý Trách nhiệm Agent (Agent Liability Consultant)
AI Agent Rights & Liability Consultant

🟣 TẦNG 3 — Tương lai xa (2028–2030+)
Khi agent tự ký hợp đồng, chuyển tiền, hoặc đưa ra quyết định y tế dẫn đến thiệt hại — ai chịu trách nhiệm? Vendor AI (OpenAI/Anthropic)? Doanh nghiệp deploy agent? Người dùng? Đây là câu hỏi pháp lý chưa luật nào trả lời đầy đủ. Agent Liability Consultant là luật sư/chuyên gia pháp lý hiểu đủ AI để tư vấn phân bổ trách nhiệm và thiết kế hợp đồng phù hợp.

Phục vụ loại DN nào? | • Doanh nghiệp triển khai agent có quyền ra quyết định tài chính hoặc y tế
• Công ty bảo hiểm muốn ra sản phẩm AI liability (Munich Re, Lloyd's đã làm từ 2024–2025)
• Tòa án và cơ quan nhà nước cần chuyên gia giám định trong tranh chấp liên quan agent
• Startup AI muốn thiết kế Terms of Service và SLA khi bán agent cho enterprise
• Ngân hàng và bệnh viện muốn protect mình trước khi bị kiện vì agent fail

Phục vụ nhiều nhất | Ngân hàng và bệnh viện — vì đây là 2 ngành mà thiệt hại do agent fail có giá trị lớn nhất và nguy cơ kiện tụng cao nhất.

Phục vụ như thế nào? | • Soạn thảo điều khoản hợp đồng AI: phân bổ liability giữa vendor, deployer, user cuối
• Tư vấn audit trail: log đủ để chứng minh quyết định là của agent hay của người nào
• Phân tích pháp lý quốc tế: EU, US, Singapore xử lý AI liability khác nhau thế nào
• Hỗ trợ insurance underwriting: rủi ro nào bảo hiểm cover, exclusions nào phù hợp
• Tư vấn disclosure: user phải được thông báo gì trước khi agent ra quyết định ảnh hưởng họ
• Cập nhật liên tục khi EU AI Act, VN data law và case law mới xuất hiện

Ví dụ thực tế | Một công ty fintech VN (tên giả định) deploy agent tự động giải ngân khoản vay nhỏ. Agent approve khoản vay cho tài khoản gian lận do lỗi RAG retrieval. Khách hàng thật bị từ chối bất công, người vay gian lận mất tích. Agent Liability Consultant (năm 2028): xác định fintech chịu 60% liability vì không có adequate guardrail, AI vendor chịu 40% vì model documentation sai. Fintech phải bồi thường + review toàn bộ quy trình.

Kỹ năng cốt lõi | Pháp lý (contract law, tort law, fintech regulation); hiểu AI agent đủ để giải thích cho tòa án; risk assessment; technical writing; regulatory affairs | Lương tham chiếu | $150k–$350k/năm. Legal + AI = top earner combination.
